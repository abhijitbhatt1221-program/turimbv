TOURIM All Device Friendly Update
=================================

This package includes a responsive CSS hardening patch for:
- Mobile phones: 320px to 430px
- Larger phones: 431px to 700px
- Tablets: 701px to 900px
- Small laptops: 901px to 1180px
- Large desktops: 1400px+

Updated areas:
- Sticky mobile-friendly header
- Mobile hamburger menu spacing
- Hero section and quotation form
- Search box and action buttons
- Package/destination/hotel/blog cards
- Offer banners and gallery cards
- Detail pages and booking sidebar
- Policy/terms page including large tables
- Footer policy links
- Admin dashboard layout on small screens
- Overflow/horizontal-scroll prevention
- Touch-friendly button sizes
- Old SitePro/chat floating widget hidden by CSS

After uploading, clear browser cache or hard refresh:
Windows: Ctrl + F5
Mobile: open in private/incognito or clear browser cache

Important:
If using WordPress, upload this folder as the active theme or replace existing theme files.
If using InfinityFree root upload, put the correct files inside /htdocs/ and do not include /htdocs in the browser URL.
